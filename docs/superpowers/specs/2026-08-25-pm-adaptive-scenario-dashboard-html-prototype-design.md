# PM 적응형 시나리오 대시보드 HTML 시안 설계

## 목적

실제 API 또는 Azure OpenAI 연결이 없는 상태에서도 PM이 인터뷰 진행 화면과 응답자별 진행 가이드를 시연할 수 있는 독립 HTML 화면을 제공한다. 이 시안은 실제 대시보드의 정보 구조를 따르되, 서버·세션·프로젝트 데이터에는 연결하지 않는다.

## 범위

- 파일 위치: `frontend/web/wireframes/`
- 산출물: 브라우저에서 바로 열 수 있는 단일 HTML 파일
- 대상: PM 전용 인터뷰 참관 대시보드 시연
- 제외: API 호출, 로그인, 실제 세션 생성, 파일 업로드, 데이터 저장, 기존 React 화면 수정

## 화면 구조

1. 상단 바
   - Gromit 로고, `PM dashboard` 역할 배지, 현재 프로젝트명, 세션 상태, `인터뷰 시작`과 `세션 목록` 버튼을 배치한다.
2. 메인 참관 영역
   - 좌측에 응답자 화면 미리보기와 현재 질문을 표시한다.
   - 우측에 실시간 진행 현황, 응답 수, 질문 진행도, 현재 질문 흐름을 표시한다.
3. 응답 입력 제어 영역
   - PM 시연자가 응답 텍스트를 직접 입력하거나 예시 응답 버튼을 눌러 확정 응답을 추가한다.
   - 초기화 버튼은 HTML 내부의 시연 상태만 되돌린다.
4. 하단 전체폭 `응답자 맞춤 시나리오` 패널
   - 응답이 2개 미만이면 분석 대기 상태를 표시한다.
   - 2개 이상이면 성향, 판단 신뢰도, 판단 근거 요약, 권장 진행 방식, 다음 확인 포인트, 피해야 할 방식, 질문 진행도를 표시한다.

## 성향 판단 규칙

시연 규칙은 응답 텍스트를 브라우저 내부에서만 읽는다. 실제 개인정보, 응답자 ID, 세션 ID는 사용하거나 표시하지 않는다.

- `비교·검토형`: `비교`, `vs`, `장단점`, `둘 다`, `가격`, `기능` 등의 비교 표현이 두 개 이상일 때
- `브랜드 선호형`: 동일 브랜드명(갤럭시, 아이폰, 삼성, 애플 등)이 반복될 때
- `상세 설명형`: 평균 답변 길이가 긴 경우
- `짧은 응답형`: 평균 답변 길이가 짧은 경우
- `균형 응답형`: 위 조건에 해당하지 않는 경우

판단 우선순위는 비교·검토형, 브랜드 선호형, 상세 설명형, 짧은 응답형, 균형 응답형이다. 응답이 추가될 때마다 다시 계산한다.

## 상호작용

- `예시 응답 추가` 버튼은 성향별 문장을 채워 넣고 응답 목록에 추가한다.
- `응답 반영` 버튼은 직접 입력한 텍스트를 확정 응답으로 추가한다.
- 각 추가 후 좌측의 대화 미리보기, 우측의 진행도, 하단 시나리오가 즉시 갱신된다.
- 응답 2개 이전에는 어떤 성향도 확정으로 표시하지 않는다.
- `시연 초기화`는 브라우저 메모리 상태만 초기화한다.

## 디자인 원칙

- 이전 Gromit 시안의 Apple 계열 다크 톤을 유지한다.
- 높은 대비의 타이포그래피, 반투명 카드, 파란 강조색, 절제된 그림자와 미세한 전환 효과를 사용한다.
- 시나리오 패널은 메인 화면 아래의 전체 너비 카드이며, 작은 모달이나 떠 있는 창으로 만들지 않는다.
- 좁은 화면에서는 좌우 열을 한 열로 전환한다.

## 검증 기준

1. HTML 파일을 직접 열어도 별도 서버/API 없이 렌더링된다.
2. 응답 1개에서는 분석 대기 안내가 보인다.
3. 응답 2개 이후 성향과 세 개의 진행 가이드 카드가 표시된다.
4. 비교 예시·브랜드 예시·긴 응답·짧은 응답에 따라 결과가 바뀐다.
5. 응답자 ID, 세션 ID, Project Access ID, 실제 원문 외부 데이터가 표시되지 않는다.
6. 기존 애플리케이션 소스와 백엔드는 수정하지 않는다.

## 제약

- localhost에서만 확인한다.
- Git commit, push, PR, 배포를 하지 않는다.
