# Git Push 권한 제어 규칙

사용자(김은향)의 명시적인 허락이나 지시가 없는 한, **절대로 `git push` 명령어를 임의로 실행하지 마세요.**
코드 수정 후 `git status`, `git diff`, `git add`, `git commit` 등의 명령어는 실행하여 커밋까지 준비할 수 있으나, 최종적으로 원격 저장소에 푸시(`git push`)하는 작업은 반드시 사용자의 동의를 구하거나 사용자가 직접 수행하도록 안내해야 합니다.

- **절대 금지**: 사용자 허락 없이 `git push` 명령어 실행
- **권장 사항**: 커밋을 완료한 후 사용자에게 "푸시(Push)해도 될까요?" 라고 물어보기
